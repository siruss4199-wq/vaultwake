## Verified context that reduces duplicate work

- WIPO confirms the Global Brand Database covers international marks and marks
  from participating national offices, but it warns that national coverage can
  be incomplete and that national IP registers should also be consulted:
  https://www.wipo.int/en/web/global-brand-database
  https://www.wipo.int/en/web/madrid-system/check-availability
- A Mongolia-based IP practice confirms **Mongolian trademark registrations and
  applications are published in the WIPO Global Brand Database**:
  https://delgerip.com/trademark-search/
  This means an owner-completed WIPO search with Mongolia checked can cover
  useful Mongolian records, although the local register is still a desirable
  independent verification.
- TMview explicitly aggregates participating national, regional and
  international offices, but a readable search form is not equivalent to
  submitted query results:
  https://www.tmdn.org/tmview/advancedSearch.html
- WIPO's Madrid Monitor documentation states that it **does not offer a public
  API for automated search** and that direct automated querying is disallowed:
  https://www3.wipo.int/madrid/monitor/en/
- Mongolia IP Office (IPOM) official contact:
  https://www.wipo.int/en/web/country-profiles/contact?code=mn
  email **ipinfo@ipom.gov.mn**, phone **(+976) 327 638**.
