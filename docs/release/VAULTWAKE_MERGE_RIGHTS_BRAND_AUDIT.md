## Preliminary name check
- Working public name: **Vaultwake Merge**.
- Public internet search on 2026-11-04 did not identify a clearly indexed game using the exact phrase Vaultwake Merge.
- The word **vaultwake** also refers to the unrelated `miller-joe/vaultwake` self-hosted Vault software on GitHub.
- A distinct Android casual title, **Vault Merge Coin Stacker**, exists.
- Similar titles/phonetics and registered marks may still conflict. **No complete trademark database search was conducted.** Search WIPO Global Brand Database, USPTO Trademark Search and relevant national offices (including Mongolia) for exact and confusingly similar terms; review software/game classes and actual goods/services. Owner or trademark counsel must sign off before commercial release.
