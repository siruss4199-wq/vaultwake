# Real-device first-session checklist

Status: **UNVERIFIED** until a human records device/OS/browser version, candidate SHA/preview URL, date and outcomes. Run iPhone Safari and Android Chrome for 20–30 minutes; screenshots of actual browser bars are required.

- [ ] With portrait browser bars visible, check notch/home-indicator clearance, all order cards, map/menu/energy controls, scrolling to the Shed and opening every slot. Expand/collapse the bars and rotate back to portrait; confirm no clipped controls or accidental part moves while scrolling.
- [ ] Start a fresh camp: 100 available, natural refill 50, +50 bonus. Tap energy for the explanation; distinguish refill limit from storage max 200. Check text at the device's normal and larger accessibility text sizes.
- [ ] Complete generate → merge → ordinary order → Gold order → restoration. The hand must not block taps/drags; rewards must be visible once; the next restoration objective must be clear. Basic must show no ad offer.
- [ ] Continue naturally through several orders/restorations. Inspect long item names, progress counts, rare items, reward labels and horizontal order scrolling. Confirm sound/haptics match settings. Optional energy purchases must show price/amount/remaining quota and reject insufficient coins or cap overflow.
- [ ] Reload, go Home/Continue, switch apps for several minutes, lock/unlock, and return with browser bars visible. Preserve board, coins, completed builds, energy apart from legitimate refill, and paid milestones. Repeat with an existing camp; no 100-energy top-up or replayed rewards.
- [ ] In the CrazyGames QA portal, verify loading/gameplay lifecycle, muted audio, performance and Basic ads-off on the exact ZIP/SHA. Only when a later Full stage is permitted, separately verify real rewarded-ad success, skip/error/unavailability, interruption, duplicate callbacks and daily quota. No production upload or ad enablement is authorized by checking this list.

Record each failure with expected/actual behavior, reproduction, screenshot/video and save-copy reference. A browser-engine emulator or SDK stub cannot sign off a physical-device/production-SDK checkbox.
